Solarity Conduit

Conduit bending workshop · 3/4″–2″ EMT

A 3D, browser-based trainer for marking, placing, and bending EMT conduit, then fitting it to real field jobs on a work wall.

  • Floor hand bender for 3/4″–1-1/4″ and an electric one-shot bender for 1-1/2″–2″, with deducts, gain, and springback
  • Mark → Place → Bend → Inspect, with lessons from 90° stubs to 4-point saddles, graded against the true bent geometry
  • Six field jobs: lay out on the wall, cut to length, install, and get graded on the fit

Sewing Simulator

Sewing workshop · Singer M1500

A 3D, browser-based trainer for a household sewing machine. Take the parts on and off, thread it, and sew practice seams, with every step following the Singer M1500 manual.

  • Seven-step guided threading through every guide, the tension discs, the take-up lever, and the needle
  • Every stitch is drawn on the top and the underside, so tension problems show up like they would in real life
  • Seams are graded, parts come off in the manual's order, and it works on phones and tablets

Basic Image Recognition Trainer

A convolutional neural network built in PyTorch that learns to tell cats from dogs, with a Streamlit interface for showing the data and running predictions.

What it does

The model trains on labeled photos and then predicts which category a new image belongs to. Right now it sorts cats from dogs, and it was trained on 20,000 cat images and 20,000 dog images. The network itself isn't tied to cats and dogs: it can learn to sort any objects, as long as the training data is formatted correctly.

How it's built

  • Images are read as three color values per pixel (0–255) and normalized before training.
  • The model is a small CNN: two convolution layers, each followed by ReLU and max pooling, then flattened into the classifier.
  • Training runs through a standard PyTorch loop of forward pass, loss, backpropagation, and optimizer step, followed by a validation pass against test data.
  • Average loss is recorded during training and plotted, so you can watch the model improve.
  • Settings like learning rate, batch size, epochs, data folders, and device (CPU/GPU) live in one config file.
  • Streamlit provides the interface and charts.

What's next

Make training more generic, so it works with other image sets and any number of categories, not just two.

Follow along: Machine learning… learning and Basic features of image recognition.
